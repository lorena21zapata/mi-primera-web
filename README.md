ABOUT THE PROJECT 
This project is my personal portfolio, designed to
showcase my background, interests, skills and projects at the
intersection of translation, localization and software development.

The website reflects my professional journey as a translator exploring
software development, highlighting how linguistic knowledge and
technological skills can work together to create meaningful digital
experiences.

Its visual identity combines a dark cyberpunk aesthetic with neon
accents, interactive elements and a responsive layout.

FEATURES - 
Responsive design for desktop, tablet and mobile devices. 
-Light and dark mode, with the selected preference saved in local
storage. 
- Interactive terminal-inspired interface. 
- Custom animations and visual transitions. 
- Language profile presenting Spanish, English
and French proficiency. 
- Project showcase covering web development,
software development and localization. 
- Cyberpunk-inspired visual
design with geometric cards and neon accents.

TECHNOLOGIES 
- HTML5: semantic structure and content. 
- CSS3: styling
and visual presentation. 
- Tailwind CSS 4: utility-first styling and
responsive design. 
- JavaScript: interactive functionality and theme
switching. 
- Google Fonts: custom typography. 
- Git and GitHub: version
control and deployment.

DESIGN SYSTEM - Ink (#0A0614): main background. - Panel (#120A24): cards
and surfaces. - Plum (#1C1038): secondary surfaces. - Orchid (#FF4FD8):
highlights and accents. - Neon (#35F2FF): interactive details. - Lilac
(#B9A4FF): secondary accents. - Pearl (#F6EEFF): main text. - Mute
(#A99BC7): secondary text.
